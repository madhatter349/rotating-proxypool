How it works

A self-contained lifecycle: discover → validate → score → rotate → retire.

🔎
Discover

28 GitHub proxy-list sources fetched on an hourly schedule, with a per-source cap so huge lists can't flood the pool.

✅
Validate

Every candidate is tested with a real HTTPS request (CONNECT tunneling / SOCKS handshake), not just a TCP ping.

📊
Score

0–100 reliability score from success rate, latency, freshness and stability. Slow proxies (>2.5s) are excluded from rotation.

🔄
Rotate

Weighted-random selection favors fresh, fast, proven proxies while keeping exit diversity. Failed upstreams are retried and cooled down.

♻️
Self-maintain

Healthy → degraded → quarantined → retest → healthy/dead. Stale rows are cleaned up automatically.

🔐
Secure gateway

Fail-closed basic auth on every request. Private/reserved IPs are blocked. Credentials are never forwarded upstream.
